# QDII 额度雷达独立账号

额度雷达在应用内使用昵称、邮箱和密码注册，通过邮件中的链接激活账号。不再使用验证码，也不跳转统一账号中心。

## 用户流程

- `/register`：填写昵称、邮箱、密码并提交，查收激活邮件。此时尚未创建可登录的账号。
- `/activate?token=…`：点击邮件链接打开页面，页面自动提交激活请求，成功后登录并返回注册前的看板或额度动态。链接 24 小时内有效，可在其他浏览器打开。
- `/login`：邮箱＋密码登录。昵称用于头像和账号菜单展示。
- `/reset-password`：填写邮箱，申请密码重设邮件；点击邮件链接后设置并确认新密码。重设链接 30 分钟内有效，成功后撤销该账号全部旧会话，使用新密码重新登录。
- 同邮箱重复注册不能覆盖已激活账号的昵称或密码。激活邮件失败可以重新提交注册表单，保留 60 秒发送冷却。
- 看板继续免登录使用，浏览器收藏不新增云同步，普通账号不获得管理员权限。

## 配置与上线

```dotenv
PUBLIC_BASE_URL=https://qdii.tomcattravel.com
ACCOUNT_AUTH_ENABLED=true
MAIL_TRANSPORT=resend
RESEND_API_KEY=<服务端配置>
RESEND_FROM=<已验证的发件人>
```

也支持现有 SMTP 配置。账号功能默认启用，但邮件配置完整才开放；`ACCOUNT_AUTH_ENABLED=false` 可关闭。生产必须使用 HTTPS。原 `ACCOUNT_CENTER_*` 配置不再读取。

`npm run dev` 使用 `http://localhost:PORT`（默认 4387），与生产 `PUBLIC_BASE_URL` 独立。开发代理可设置 `DEV_BASE_URL`。开发模式允许同端口的 localhost、127.0.0.1、[::1]，邮件链接使用发起请求的受信任本地地址，不会误跳到生产站点。生产仅接受配置的正式域名。链接不能使用任意 Host 头生成。`TRUST_PROXY_HOPS` 仅在可信反向代理后设置。

激活和重设密码邮件使用 HTML 排版（标题、品牌蓝色操作按钮、完整备用链接和底部提示），同时保留纯文本正文。邮件布局使用表格和内联样式，不依赖外部图片或字体。账号邮件直接调用 Resend/SMTP，与订阅提醒队列独立；提醒入口隐藏不影响激活邮件。`MAIL_TRANSPORT=file` 只供本地测试，生产禁止使用。

邮件失败时不留下可用链接；`lastAccountMailFailure` 元数据只记录失败时间和安全错误码，不存服务商正文、密码或链接。邮件配置完整不等于投递成功。若办公安全软件拦截 `api.resend.com`，需按组织流程放行；Resend 仅发送用途的 API Key 不能查询域名列表，`restricted_api_key` 不是发信结果。

部署前备份 SQLite 和 `.env`，上线后实际验证激活邮件、点击激活、密码登录、重设邮件和退出。反向代理不记录激活/重设 URL 的查询参数；页面使用 no-referrer，并在读取链接后从地址栏移除 token。

## 数据与认证约束

- 已有本地账号继续有效，新增用户保存填写的昵称。旧统一账号表保留但不参与认证，不复制其密码，不按相同邮箱自动合并；旧服务端订阅数据不自动迁移。
- `local_account_users` 保存本产品用户；未激活注册和密码重设事务使用 `local_account_links`。旧验证码事务不再读取。
- 昵称 1–40 字符，新密码为 8–128 字符，须包含字母和数字，不要求特殊符号（已有密码仍可正常登录）；密码用独立随机盐与 scrypt（N=32768、r=8、p=3）生成摘要。待激活注册也只存密码摘要。
- 邮箱去首尾空白并转小写。本应用内唯一，激活前不能登录。
- 邮件链接使用 256 位随机令牌，数据库只存令牌摘要；用途隔离、限时、单次使用，邮件服务确认接收后才启用。普通 GET 预览不改变账号状态，页面脚本 POST 才完成激活。
- 链接可跨浏览器使用。激活成功后删除该邮箱其他待用链接，重复提交不能重复创建账号。密码重设还绑定申请时的密码版本，重设后删除全部旧会话及链接，防止旧链接或并发旧密码登录恢复访问。
- 同邮箱每 60 秒最多发送一次、每小时最多 5 次；同 IP 每小时最多 15 次。密码登录同邮箱每小时最多 10 次尝试（成功/重设后清除邮箱预算），同 IP 每小时最多 30 次；另受应用通用限流。关键限流持久化，重启不重置。
- 未知邮箱的找回密码请求返回统一提示。密码错误与未知邮箱使用相同错误消息。
- 会话最多 8 小时，登录时更换标识，数据库保存标识摘要；HttpOnly / SameSite=Lax，生产使用 Secure / __Host- Cookie，不共享给其他产品。
- 所有认证修改请求校验来源，退出还校验会话 CSRF。无来源的请求不会直接放行；`Origin: null` 需浏览器的 `Sec-Fetch-Site: same-origin`。跳转地址仅接受已知产品页面。

## 验证

```sh
npm test
npm run build
PLAYWRIGHT_MODULE=/absolute/path/to/playwright node scripts/account-smoke.mjs
# 复现 .env 含生产地址、本地开发运行的情况
ACCOUNT_SMOKE_DEV=true PLAYWRIGHT_MODULE=/absolute/path/to/playwright node scripts/account-smoke.mjs
```

自动测试使用临时 SQLite、模拟邮件提供商和文件邮箱，不发送真实邮件。浏览器测试覆盖三个注册字段、查收邮件提示、点击链接激活、昵称显示、登录、邮件链接重设密码、原生退出、匿名身份保留、失效链接和响应式布局。截图位于 `outputs/local-account/`，不替代生产实际投递验收。
